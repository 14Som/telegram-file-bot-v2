# 2026-11-07 — Publish 2.6.10 and phone 3.13.8

## What changed
- Released desktop 2.6.10 (both EXEs) and phone 3.13.8 (code 38) on GitHub.
- The phone can upload files into the folder being browsed (up to 2 GB).
- Phone transfers and vault restore use PyCryptodome's native AES instead of Telethon's Python fallback, so uploads and the startup restore are faster.
- Video streaming hands chunks to the player immediately and keeps a background prefetch builder going, so movies start without a full download; videos named after their release year (no real extension) play directly using their MIME container.
- The phone restores the vault index on open, saves it on close, and shreds the staged archive in app-private storage.
- The desktop window opens with a loading screen while the vault snapshot restores, and a second launch focuses the open window.
- Snapshot uploads are serialized, so sync-save and close-save cannot overlap.

## Why
These features were built and tested locally but never published, so users were still on 2.6.6 / 3.12.2.

## Files
- `desktop/` — `tg.py`, `streamcache.py`, `filetypes.py`, `playback.py`, `server.py`, `native.py`, `vaultstore.py`, `ui/*`.
- `android/` — `MainActivity.java`, `build.gradle` (3.13.8), `python/main.py`.
- `installer/setup.py` — installer version 2.6.10.
- Binaries at the repo root: `TelegramFileExplorer.exe`, `TelegramFileExplorerSetup.exe`.
